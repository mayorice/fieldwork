Fieldwork Support

Need help with Fieldwork? This page provides basic support information for the app.

Common support topics

Fieldwork is designed to work offline and save information locally on your device. If you experience an issue, try closing and reopening the app first, then confirm you are using the latest available version.

Reports and exports

Generated PDF, Word and ZIP files are created from the information stored in the app. If an export does not complete, try rebuilding the export and confirm the device has sufficient free storage.

Data and privacy

Fieldwork does not collect or transmit personal information or user data. See the Privacy Policy for details.

Contact

For support enquiries, use the developer contact details listed on Fieldwork's App Store page.
